## Инизиализация нового проекта Laravel
## Иснструкция по модификации файла hosts для обхода региональных ограничений Packagist
>При возникновении сетевых тайм-аутов или блокировок со стороны CDN при выполнении команд "сomposer crate-project" 
>или  ```composer install``` необходимо перенаправить трафик на валидные IP-адреса репозиториев в обход локальных 
> DNS-серверов
1. Откройте конфигурационный файл по пути: ```C:\Windows\System32\drivers\etc\hosts```
2. Вставьте подготовленный блок записей в конец файла: 
``` text
138.199.37.232 packigist.org
138.199.37.232 repo.packigist.prg 
```
Либо зайдите в настройки OSPanel, перейдите во вкладку "Файл HOSTS" и добавьте подготовленный блок записей в конец файла

### 1. Актуализация пакетного менеджера
Обновление локального исполняемого файла Composer до последней стабильной версии
```angular2html
bash 
composer self-update
```

### 2. Инициализация каркаса приложения
Развертывание чистого скелета Laravel в текущую рабочую директирию в которой мы находимся
```bach
composer create-project laravel\laravel .
```
```bach
composer create-project laravel\laravel learnlaravel13.local
```
После чего необходимо перейти в директорию с проектом
```bach
cd learnlaravel13.local
```

### 3. Конфигурация Api слоя
Инсталляция и автоматическая натсройка пакета аутентификации (Laravel Sanctum), а также генерация базовых 
маршрутов для работы в режиме Stateless API:

```bash
php artisan insall:api
```

### 4. Экспорт конфигурации Cors
Публикация конфигурационного файла config/cors.php для управления политиками кросс-доменных запросов
```bash
php artisan config:publish cors
```

### 5. Инициализация символной ссылки для Storage
Создание симлинка из пбличной директории public/storage в изолированнрое хрнилище strage/app/public
для обеспечения контролируемого HTTP-доступа к медафайлам:

```bash
php artisan storage:link
```
### 6. Маршрутизация веб-сервера 
Создание или перезапись файла конфигурации .htaccess в корневой директории для перенапраления входящего трафика на
фронт-контроллер public/index.php
```apache
RewriteEngine On
#Перенаправление всех входязих HTTP запросов в публичную директорию public/
RewriteRule ^(.*)$ public/$1 [L]
```

## Рзвертывание существующего проекта из репозитория

### 1. Клонирование и инициализация зависимостей
Загрузка исходного кода из удаленного репозитория и установка backend-зависимостей согласно ```composer,lock```
```bach
git clone https:/github.com/RG/learnlavarel13.git```
cd
composer install
```

### 2. Подготовка окружения и генерация app_key (ключа приложения)
```bach 
cp .env.example .env
php artisan key:generate
```

### 3. Миграция и содирование базы данных

Выполнение базовых DDl-скриптов для построения структуры таблиц с параллельным наполнением 
справочников тестовыми или системными данными
```env
DB_CONNECTION=mysql
DB_HOST=MySQL-8.4
DB_PORT=3306
DB_DATABASE=learnlaravel13
DB_USERNAME=root
DB_PASSWORD=

SESSION_DRIVER=file
```
